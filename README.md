# Xây dựng Landing Page với Bootstrap

Bài thực hành xây dựng một Landing Page chuyên nghiệp sử dụng Bootstrap 5 với đầy đủ các thành phần:
- **Navbar**: Thanh điều hướng responsive với nút toggle và căn lề menu sang phải (`ms-auto`).
- **Hero Section**: Phần mở đầu nổi bật với tiêu đề, slogan và nút kêu gọi hành động (Call To Action).
- **Grid System & Cards**: Trình bày danh sách dịch vụ 3 cột bằng Bootstrap Grid (`row`, `col-md-4`) và thẻ `card`.
- **Footer**: Chân trang chuyên nghiệp hiển thị bản quyền website.

## Cài đặt
Sử dụng Bootstrap 5 qua CDN. Mở file `index.html` trực tiếp trên trình duyệt để kiểm tra giao diện.
